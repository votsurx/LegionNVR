# 🛡️ Legion NVR V6.0 — PLAYER EDITION

**Legion NVR** — мощная система видеонаблюдения с AI-детекцией, непрерывной записью и встроенным плеером для просмотра архива.

---

## 🆕 ЧТО НОВОГО В V6.0

- 🎬 **Встроенный плеер** с таймлайном (24 часа)
- ⏱️ **Точная перемотка** — клик по таймлайну → видео с этого момента
- 📁 **Часовые HLS-папки** — 3600 сегментов/час, без raw/
- 🔍 **Зум таймлайна** — 24ч/12ч/6ч/3ч/2ч/1ч/30м
- 🟢 **Реальные промежутки записи** — зелёные полосы только где есть данные
- 🔴 **Метки тревог** на таймлайне
- 🗑️ **Автоочистка** — удаление записей старше N дней
- ♻️ **Авто-перезапуск** упавших сервисов (auto-heal)
- 📱 **Адаптивный интерфейс** — телефон/планшет/десктоп

---

## 🚀 ВОЗМОЖНОСТИ

### 🤖 AI-детекция
- YOLOv8n + MOG2 (гибридный режим)
- Детекция людей, машин, животных
- Настраиваемые зоны детекции
- Рамки на скриншотах и записях

### 📼 Запись
- 4 режима: по тревоге + AI, 24/7, по расписанию, по расписанию + AI
- Предзапись (настраиваемый буфер)
- Постзапись
- Непрерывная запись с часовыми HLS-папками

### 🎬 Плеер
- Таймлайн 24 часа с зумом
- Клик по таймлайну → мгновенная перемотка
- Зелёные полосы = непрерывная запись
- Красные точки = тревоги

### 🖥️ Веб-интерфейс
- Дашборд с живыми MJPEG-потоками
- Полноэкранный режим с выбором качества (320p/640p/720p/1080p)
- Цифровой зум (pinch-to-zoom на планшетах)
- Health Monitor с авто-перезапуском сервисов
- Массовое управление камерами (вкладки Основное/Стриминг/Детектор/Запись/AI)
